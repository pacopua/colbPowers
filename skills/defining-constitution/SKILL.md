# Skill: defining-constitution

## Overview
Guides the user to define the core project rules, architecture, and constraints.

## Checklist
1. Use the Read tool on `.specs/memory/constitution.md`. If it has content, exit and do nothing.
2. Use the Read tool on `.specs/templates/constitution_template.md`. To know what questions to ask to create the constitution. 
3. Ask the user about their project vision, tech stack, and core rules. Following template `.specs/templates/constitution_template.md` if it exists. 
4. Once gathered, use the Write tool to save the definitions to `.specs/memory/constitution.md` following standard markdown formatting.
